# Evidências sanitizadas

Resultados de 2026-11-16. Logs de testes sintéticos autorais e inventários de compilação; não contêm instruções ou recursos do título. A referência Unicorn foi usada apenas no fixture autoral, como ferramenta local opcional.

Os resultados HLE usam chamadas sintéticas no SDK real compilado com metadata privada da variante; não executam funções comerciais. Os testes GPU e de contexto têm receitas públicas independentes dessa metadata. O CI executa os testes sintéticos GPU/contexto; não executa o jogo.

Os arquivos estáticos ARM64 listados são saídas privadas de compilação, sem runtime Android ligado ou APK. Nenhum binário está incluído aqui. Logs brutos, capturas do título e conteúdo do disco permanecem nos diretórios ignorados.
